# Donetsk 2011

Project website for **Donetsk 2011**, a source-based reconstruction of Donetsk in 2011 in Unreal Engine 5.

Languages: Russian, Ukrainian, English, Finnish (switcher in the header, or `#ru`, `#uk`, `#en`, `#fi`).

Map data © OpenStreetMap contributors, ODbL 1.0. SRTM3 elevation: USGS. Street View panoramas are linked, never embedded.
